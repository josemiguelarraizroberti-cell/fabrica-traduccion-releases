# Fábrica de Traducción — Actualizaciones

Repositorio público exclusivo para distribuir versiones verificadas de la aplicación de escritorio **Fábrica de Traducción**.

- El código fuente permanece en un repositorio privado.
- Este repositorio no contiene manuscritos, proyectos, Biblias importadas ni credenciales.
- Cada actualización se publica como un archivo ZIP acompañado por su verificación SHA-256.
- La aplicación consulta `latest.json` para detectar nuevas versiones.
